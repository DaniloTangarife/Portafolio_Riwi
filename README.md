# Portafolio web – Danilo Tangarife

Portafolio personal construido desde cero con HTML y CSS, sin frameworks ni plantillas,
como parte de la actividad "Mi portafolio web desde cero".

Incluye presentación, sección "Acerca de mí", experiencia profesional simulada y los
proyectos realizados en clase con captura, descripción y enlace funcional.

- CSS3 (archivo separado, diseño adaptable)
